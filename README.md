## 📱 Sobre o Projeto

Este é um aplicativo mobile desenvolvido com foco em **gerenciamento de contatos**, permitindo operações completas de:

<p align="center">
  ➕ Criar &nbsp;&nbsp; 📖 Ler &nbsp;&nbsp; ✏️ Atualizar &nbsp;&nbsp; 🗑️ Deletar
